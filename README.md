# Акт с замечаниями по ПБ — ООО «БИЗНЕСПРО»

Приложение для составления акта осмотра систем противопожарной защиты с замечаниями,
фото и видео, ссылками на нормы и выгрузкой в Word, PDF и Excel.

Открыть: https://iceboyz.github.io/akt-biznespro/

Здесь лежит только собранный файл `index.html`. Исходный код — в закрытом репозитории портала
(`frontend/src/akt`, сборка `npm run build:akt`). Не правьте `index.html` вручную: он заменяется новой сборкой.

Черновики, фото и видео хранятся в браузере устройства (на сервер ничего не уходит).
